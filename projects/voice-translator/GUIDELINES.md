# 개발·운영 지침

이 프로젝트를 만들고 사용할 때 지키는 기준입니다.

## 1. 키와 비밀 정보

- API 키는 `.env` 파일에만 두고 코드에 직접 쓰지 않습니다.
- `.env`는 저장소에 올리지 않습니다. (`.gitignore`에 이미 포함되어 있습니다.)
- 키가 노출됐다면 바로 폐기하고 새로 발급합니다.

## 2. 음성·개인정보

- 학생이나 참가자의 목소리를 쓰는 수업에서는 시작 전에 사용 목적을 알리고 동의를 받습니다.
- 기본값은 녹음 파일을 저장하지 않는 것입니다. 저장이 필요하면 목적과 보관 기간을 정해 둡니다.
- 음성과 변환된 텍스트를 로그에 남길 때는 최소한으로 합니다.
- 외부 서비스로 음성이 전송된다는 점을 사용자에게 알립니다.

## 3. 안전

- 라즈베리파이는 정품 또는 규격에 맞는 전원 어댑터를 사용합니다.
- 연결하는 부품은 저전압(5V 이하) 범위에서만 씁니다. 콘센트 전원을 직접 다루는 작업은 넣지 않습니다.
- 하울링을 막기 위해 이어폰이나 지향성 마이크를 쓰고, 버튼을 누르는 동안만 말하는 방식(푸시투톡)을 기본으로 합니다.

## 4. 코드 작성

- 파이썬 3.9 이상, 기능별로 파일을 나눕니다. (음성 인식 / 번역 / 음성 합성 / 장치 제어)
- 사용하는 서비스를 바꿀 수 있도록 서비스별 코드는 한 파일에 모읍니다.
- 설정값(언어, 마이크 번호, 서비스 이름)은 코드 안에 흩어 쓰지 않고 한곳에 둡니다.
- 모르는 부분은 AI에게 시킨 프롬프트를 `prompt.md`에 남깁니다.

## 5. 성능 기록

- 단계마다 지연 시간(말을 끝낸 뒤 소리가 나오기까지)과 인식 정확도를 `docs/`에 표로 기록합니다.
- 클라우드 방식과 장치 안에서 처리하는 방식을 같은 문장으로 비교합니다.

## 6. 문서

- 서비스나 구조를 바꾸면 README의 "결정할 것"을 갱신합니다.
- 실습 자료로 쓸 때는 영상 대본과 같은 순서로 단계를 정리합니다.
