# 실시간 한↔영 통역 장치 (Realtime Translator)

한국어로 말하면 영어 음성으로 들려주고, 상대방의 영어를 듣고 한국어로 알려주는 IoT 장치 프로젝트입니다.
해외 교육 현장에서 쓰는 것을 목표로 하며, 라즈베리파이 5에서 파이썬으로 동작합니다.

> 상태: 기획 단계 (아직 구현 전)

## 동작 구조

```
[말하기: 한 → 영]
마이크 → 한국어 음성 인식(STT) → 영어 번역 → 영어 음성 합성(TTS) → 스피커

[듣기: 영 → 한]
마이크 → 영어 음성 인식(STT) → 한국어 번역 → 한국어 자막 또는 이어폰 음성
```

문장 단위로 처리하므로 말한 뒤 1~3초 정도 지연이 있습니다.

## 개발 단계

| 단계 | 내용 | 폴더 |
|------|------|------|
| 1 | PC에서 시제품 만들기 (마이크 → 영어 음성) | `pc_prototype/` |
| 2 | 푸시투톡 버튼과 상태 LED 붙이기 (GPIO) | `pi5/` |
| 3 | 라즈베리파이 5로 옮기고 지연·품질 측정 | `pi5/` |
| 4 | 인터넷이 불안정할 때를 위한 오프라인 방식 검토 | `docs/` |

## 준비물

- 라즈베리파이 5, 전원 어댑터(정품 권장), microSD 카드
- USB 마이크, 이어폰 또는 스피커
- 푸시 버튼 1개, LED 1개, 저항, 점퍼선
- Python 3.9 이상
